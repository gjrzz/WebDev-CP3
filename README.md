# ⬡ GameVault

Aplicação web de cadastro de jogos favoritos, desenvolvida com HTML, CSS e JavaScript puro como atividade da disciplina de Desenvolvimento Web — FIAP.

## 🚀 Como rodar

Sem necessidade de servidor ou instalação. Basta clonar o repositório e abrir o `index.html` no navegador.

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
# abrir index.html no navegador
```

## ✅ Funcionalidades

- Tela de login com validação de campos e mensagem de erro na tela
- Adicionar jogo ao **final** da lista
- Adicionar jogo ao **início** da lista
- **Editar** jogo individualmente (por índice)
- **Remover** jogo individualmente (por índice, evitando bug com itens duplicados)
- Contador dinâmico de itens
- Suporte a tecla **Enter** nos campos de input

## 🗂 Estrutura do projeto
